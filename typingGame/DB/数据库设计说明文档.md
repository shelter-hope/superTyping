# 打字游戏数据库设计说明文档

## 1. 数据库概述

本数据库设计用于支持一个打字训练游戏系统，包含用户管理、游戏记录、词库管理、排行榜、数学模型调整、社交系统和AI对话等功能。数据库采用MySQL 8.0.3版本，使用InnoDB存储引擎，默认字符集为utf8mb4。

## 2. 公共字段说明

在数据库设计中，以下字段为公共字段，在多个表中重复使用：

| 字段名                 | 数据类型         | 描述            |
| :------------------ | :----------- | :------------ |
| `id`                | INT          | 主键ID，自增       |
| `user_id`           | INT          | 关联用户ID        |
| `create_time`       | DATETIME     | 创建时间          |
| `update_time`       | DATETIME     | 更新时间          |
| `create_id`         | INT          | 创建者用户ID       |
| `update_id`         | INT          | 更新者用户ID       |
| `is_active`         | TINYINT(1)   | 是否启用          |
| `is_public`         | TINYINT(1)   | 是否公开          |
| `is_read`           | TINYINT(1)   | 阅读状态          |
| `is_top`            | TINYINT(1)   | 是否置顶          |
| `is_mute`           | TINYINT(1)   | 是否静音          |
| `is_recall`         | TINYINT(1)   | 是否撤回          |
| `is_true_mean`      | TINYINT(1)   | 是否为有意义字符串     |
| `is_parent`         | TINYINT(1)   | 是否为下一轮父本      |
| `difficulty_level`  | TINYINT(1)   | 难度等级（1-5）     |
| `proficiency_level` | TINYINT(1)   | 熟练度等级（1-5）    |
| `avg_speed`         | DECIMAL(5,2) | 平均打字速度（字符/分钟） |
| `peak_speed`        | DECIMAL(5,2) | 峰值打字速度（字符/分钟） |

| `peak_accuracy`     | DECIMAL(5,2) | 峰值准确率（%）      |

## 6. 总结

本数据库设计完整覆盖了打字游戏系统的所有功能需求，包括：

1. **用户管理**：用户信息、每日统计、历史快照
2. **游戏核心**：游戏记录、怪物数据、字符统计
3. **词库系统**：用户自定义词库、系统词库
4. **排行榜**：游戏成绩排行
5. **数学模型**：难度调节、个性化参数
6. **系统配置**：全局参数、用户应用配置
7. **社交系统**：好友关系、聊天消息
8. **AI对话**：AI陪练、问题解答

数据库结构设计合理，索引优化充分，初始数据完整，为打字游戏系统提供了坚实的数据基础。通过遗传算法和数学调节模型的应用，可以为用户提供个性化的打字训练体验，帮助用户提高打字速度和准确率。
