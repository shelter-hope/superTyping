# 打字训练游戏动态难度调节数学模型

## 一、概述

本系统采用基于多维度指标融合的动态难度调节数学模型，通过实时分析玩家表现，自动调整游戏难度参数（怪物速度、数量、字符串长度、类型占比），实现"以战代练"的训练目标，同时兼顾游戏的趣味性与挑战性。

---

### 2.3 辅助参数（常量/阈值）

| 参数名称 | 符号 | 取值 | 作用 |
| :--- | :--- | :--- | :--- |
| 速度调节阈值（低/高） | A1/A2 | 0.4/0.85 | 准确率低于A1减速，高于A2加速 |
| 数量增长阈值（低/高） | S1/S2 | 40/120 | 速度低于S1停止增加数量，高于S2加速增加数量 |

| 轮次增长系数 | K0 | 1.1 | 轮次对参数调节的基础放大系数 |
| 易错字符权重系数 | We | 1.5 | 易错字符占比对难度调节的放大系数 |
| 平滑调节系数 | α | 0.8 | 控制难度系数的变化幅度，避免参数突变 |

### 2.4 核心权重参数

所有权重参数总和为1，确保计算逻辑的合理性：

| 参数名称 | 符号 | 取值 | 核心含义 | 作用逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| 实时准确率权重 | WA | 0.35 | 实时准确率At的影响权重 | 实时准确率是最核心的难度适配依据，玩家准确率越高，难度提升贡献越大 |
| 实时速度权重 | WS | 0.25 | 实时打字速度St的影响权重 | 速度直接反映玩家操作能力，速度越快，需通过增加怪物数量/速度提升难度 |
| 单字符错误率权重 | WE | 0.2 | 单轮字符平均错误率Eit的影响权重 | 聚焦玩家本轮易错点，错误率越高，系统需适当降低难度增长幅度 |
| 历史平均准确率权重 | WAh | 0.1 | 历史平均准确率Ah的影响权重 | 参考玩家长期表现，避免单轮波动导致难度突变 |
| 历史峰值速度权重 | WSh | 0.05 | 历史峰值速度Shmax的影响权重 | 反映玩家能力上限，用于微调难度，避免难度低于玩家实际能力上限 |
| 易错字符占比权重 | WRe | 0.05 | 易错字符占比Re的影响权重 | 关联玩家历史易错字符的本轮出现频率，占比越高，难度增长可放缓 |
| 当前轮次权重 | WK | 0.1 | 当前轮次K的影响权重 | 随轮次递增提升难度基数，确保游戏"越打越难" |

### 2.5 辅助计算参数

| 参数名称 | 符号 | 取值/计算方式 | 核心作用 |
| :--- | :--- | :--- | :--- |
| 最大参考速度 | Smax | 150字符/分钟 | 标准化实时速度St，转换为[0,1]区间值 |
| 参考峰值速度 | Sref | 120字符/分钟 | 标准化历史峰值速度Shmax，确保与实时指标取值范围一致 |
| 初始难度系数 | D0 | 0.3 | 游戏首轮的默认难度系数，适配初始无历史数据的玩家 |

## 三、核心调节算法模型

### 3.1 综合难度系数（Dt）计算

首先通过加权求和计算单轮综合难度系数，作为所有参数调节的基础依据：

```
Dt = α·Dt−1 + (1−α)·[WA·At + WS·(St/Smax) + WE·E_avg + WAh·Ah + WSh·(Shmax/Sref) + WRe·Re + WK·log2(K)]
```

**公式说明：**

| 符号 | 说明 |
| :--- | :--- |
| Dt−1 | 上一轮综合难度系数，初始值D0=0.3 |
| α | 平滑调节系数，取值0.8，控制难度变化幅度 |
| At | 实时准确率 |
| St | 实时打字速度 |
| Smax | 预设最大参考速度（150字符/分钟） |
| E_avg | 单轮所有字符的平均错误率 |
| Ah | 历史平均准确率 |
| Shmax | 历史峰值速度 |
| Sref | 参考峰值速度（120字符/分钟） |
| Re | 易错字符占比 |
| K | 当前轮次 |

**权重分配逻辑：**

- 实时指标（准确率、速度、错误率）总权重占80%，确保难度紧跟玩家当前表现；
- 历史指标（历史准确率、峰值速度）总权重占15%，避免单轮失误导致难度大幅下降；
- 轮次权重占5%，保障游戏难度的整体递增趋势，符合"突破舒适区"的核心目标。

### 3.2 各参数动态调节公式

#### 3.2.1 怪物基础行进速度（Vt）

```
Vt = α·Vt−1 + 0.1        At≥0.85 且 St≥Shmax×0.8
     α·Vt−1 − 0.1        At≤0.4 或 St≤20
     α·Vt−1 + (Dt−0.5)×0.2  其他情况
```

**约束**：Vt∈[0.8, 3.0]，避免速度过快或过慢导致游戏失去意义。

#### 3.2.2 单轮怪物生成数量（Nt）

```
Nt = min(25, α·Nt−1 + 1)    K≤10 且 St≥40
     min(25, α·Nt−1 + 2)    St≥120 且 At≥0.7
     max(3, α·Nt−1)         At≤0.5 或 St≤30
     α·Nt−1 + ⌊Dt×2⌋        其他情况
```

**说明**：数量增长与轮次、速度强相关，避免新手期数量过多，高手期数量不足。

#### 3.2.3 平均字符串长度（Lt）

```
Lt = max(1, α·Lt−1 − 1)      At≤0.5且 E_avg≥0.3
     min(15, α·Lt−1 + 1)     At≥0.8且 St≥80
     α·Lt−1 + ⌊(Dt−0.4)×3⌋    其他情况
```

**补充**：字符串长度采用正态分布生成，平均长度为Lt，标准差为1.5，确保长度有波动但整体符合难度预期。

#### 3.2.4 怪物类型占比调节

首先计算类型占比基础调节系数 Tt = Dt × WE × Re，再分配各类型占比：

```
Pn,t = 80% − ⌊Tt×100⌋%
Pa,t = 5% + ⌊Tt×40⌋%
Pe,t = 5% + ⌊Tt×30⌋%
Ps,t = 10% + ⌊Tt×30⌋%
```

**约束**：各占比需在取值范围内，总和为100%；

**逻辑**：难度越低，普通型占比越高；难度越高，攻击型、智慧型占比越高，增加游戏策略性。

### 3.3 易错字符关联调节（定向强化）

针对历史易错字符（错误次数Top5），在字符串生成时加入定向强化逻辑：

```
易错字符出现概率 = 基础概率 × (1 + WE × Re × Dt)
```

**说明**：基础概率为字符在词库中的自然占比，通过该公式提升易错字符的出现频率，迫使玩家针对性练习。

## 四、模型扩展与优化

### 4.1 玩家状态自适应修正

**疲劳度修正**：若连续3轮准确率下降幅度≥10%，则触发"疲劳缓冲"，下一轮参数调节幅度减半；

**进步速度修正**：若历史平均准确率近3场提升≥15%，则适当提高难度增长系数（K0调整为1.2），加速适配玩家进步；

### 4.2 游戏模式差异化调节

**无尽适应模式**：难度增长系数K0=1.1，类型占比中普通型上限提升至100%，下限提升至60%，强调自适应进化；

**词源界定模式**：难度增长系数K0=1.0，字符串长度限制解除，攻击型占比上限降低至10%，兼顾专业词库的针对性训练。

### 4.3 稳定性约束机制

**参数突变防护**：单次调节幅度不超过上一轮参数的30%，避免难度骤升骤降；

**边界锁定机制**：当参数达到取值范围边界时，停止同向调节，仅在玩家表现反向变化时解锁；

**回退机制**：若单轮准确率≤30%且速度≤20字符/分钟，下一轮自动回退至上一轮参数的80%，避免玩家挫败感。

## 五、模型验证与迭代逻辑

### 5.1 验证指标

| 指标 | 目标值 |
| :--- | :--- |
| 适配性 | 新手玩家（20-40字符/分钟）首10轮难度增长率≤15%，高手玩家（120+字符/分钟）首10轮难度增长率≥30% |
| 针对性 | 易错字符的练习频率是普通字符的1.5-2.0倍，且练习后错误率下降幅度≥20% |
| 趣味性 | 玩家连续游戏轮次≥5轮时，难度匹配度（玩家主观评分）≥7分（10分制） |

### 5.2 迭代更新

**实时迭代**：每轮游戏结束后，基于当前表现更新模型参数，应用于下一轮；

**离线迭代**：每日统计所有玩家的模型适配数据，优化权重系数（如WA、WS），提升模型通用性；

**个性化迭代**：针对单个玩家，若连续5轮难度匹配度评分≤5分，自动调整该玩家的权重系数，生成个性化调节规则。

## 六、模型应用流程

1. **初始化**：游戏首轮加载玩家历史数据，计算初始综合难度系数D0=0.3，初始化各参数为初始值；
2. **实时计算**：每轮游戏过程中，实时滚动计算At、St、Eit等核心指标；
3. **参数调节**：轮次结束后，通过模型公式计算下一轮的Vt、Nt、Lt及类型占比；
4. **字符串生成**：基于调节后的参数，结合易错字符强化逻辑，生成下一轮字符串怪物；
5. **迭代优化**：每5轮游戏后，结合玩家反馈（如主动退出、重试次数）修正模型参数，提升适配性。

## 七、扩展适配场景

| 场景 | 调整建议 |
| :--- | :--- |
| 无尽适应模式 | 将轮次权重（WK）提升至0.15，加快难度增长，强化进化机制 |
| 词源界定模式 | 将单字符错误率权重（WE）提升至0.25，弱化轮次影响，聚焦专业词库的针对性训练 |

### 7.1 关键注意事项

- 所有权重参数的总和必须为1，若调整某一参数权重，需同步调整其他参数，确保计算逻辑自洽；
- 辅助参数（Smax、Sref）可根据目标用户群体调整（如面向专业用户可将Smax设为200字符/分钟）；
- 平滑调节系数（α）建议取值范围为0.7-0.9，α越小难度变化越激进，α越大难度变化越平缓。
